About this website

Tools and structure

I am building this website in IntelliJ IDEA using HTML. It contains four pages: a home page introducing the store, a catalogue showing clothing categories and prices, a visit page with contact information and a practice feedback form, and this page explaining the development process. Relative links connect the pages. The website opens locally in a browser and does not use CSS or JavaScript.


Development and testing
